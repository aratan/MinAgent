directive per entry, written as an instruction, with the date it was observed.

Durable project decisions do not belong here; those go in the memory store.
This file is for the person, not the work.

## How this file may change

Ara may add a directive when the user states a stable preference, and must
supersede the old entry rather than appending a contradictory one. Each
directive carries the date it was observed so a stale preference can be told
from a current one.
